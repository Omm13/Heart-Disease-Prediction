The project uses the **UCI Heart Disease Dataset (Cleveland subset)** and implements a complete Machine Learning pipeline including data preprocessing, exploratory data analysis, feature transformation, model training, evaluation, model serialization, and a Streamlit-based web application.  The application accepts patient health parameters and provides a predicted heart disease risk along with the estimated probability generated by the Machine Learning model.  > **Disclaimer:** This project is developed for academic and educational purposes. The prediction and probability generated by the model are not a medical diagnosis and should not be used as a substitute for professional medical advice.  Objectives ----------  *   Analyze patient health data related to heart disease.      *   Perform data cleaning and exploratory data analysis.      *   Preprocess numerical and categorical features.      *   Develop a Machine Learning classification model.      *   Evaluate the model using standard classification metrics.      *   Save the trained model for later use.      *   Develop an interactive Streamlit web application.      *   Validate consistency between the saved model and the deployed application.       Dataset -------  The project uses the **UCI Heart Disease Dataset – Cleveland subset**.  Dataset source:  UCI Machine Learning RepositoryHeart Disease Datasethttps://archive.ics.uci.edu/dataset/45/heart+disease  The original Cleveland dataset contains **303 patient records** and 13 input attributes related to heart disease.  The original target variable contains values from 0 to 4. For this project, it was converted into a binary classification problem:  *   0 → No Heart Disease      *   1–4 → Presence of Heart Disease       The final dataset contains **303 records and 14 columns**, including the target variable.  Features Used -------------  The model uses the following patient attributes:  *   Age      *   Sex      *   Chest Pain Type      *   Resting Blood Pressure      *   Cholesterol      *   Fasting Blood Sugar      *   Resting ECG      *   Maximum Heart Rate      *   Exercise-Induced Angina      *   ST Depression (Oldpeak)      *   Slope      *   Number of Major Vessels (ca)      *   Thalassemia (thal)       Target:  *   0 → No Disease      *   1 → Disease       Technologies Used -----------------  *   Python      *   Pandas      *   NumPy      *   Matplotlib      *   Seaborn      *   Scikit-learn      *   Joblib      *   Streamlit      *   Jupyter Notebook       Project Workflow ----------------  UCI Heart Disease Dataset  ↓  Data Loading  ↓  Data Cleaning  ↓  Exploratory Data Analysis  ↓  Feature Selection  ↓  Train-Test Split  ↓  Data Preprocessing  ↓  Logistic Regression  ↓  Model Evaluation  ↓  Model Serialization  ↓  Streamlit Web Application  ↓  Heart Disease Risk Prediction  Exploratory Data Analysis -------------------------  Several exploratory analyses were performed to understand the dataset and identify patterns in the patient data.  The analysis included:  *   Target variable distribution      *   Age distribution      *   Age versus heart disease      *   Cholesterol versus heart disease      *   Maximum heart rate versus heart disease      *   Feature correlation analysis      *   Descriptive statistics      *   Unique value analysis      *   Comparison of numerical features across target classes       The dataset contains a relatively balanced target distribution:  *   No Heart Disease: **164**      *   Heart Disease: **139**       Data Preprocessing ------------------  The dataset contained missing values in:  *   ca → 4 missing values      *   thal → 2 missing values       For exploratory analysis, missing values were handled using median-based imputation.  For the final Machine Learning model, preprocessing was implemented using a Scikit-learn Pipeline to avoid data leakage.  ### Numerical Features  The numerical features were processed using:  *   Median imputation      *   Standardization using StandardScaler       Numerical features:  *   Age      *   Resting Blood Pressure      *   Cholesterol      *   Maximum Heart Rate      *   Oldpeak       ### Categorical Features  Categorical features were processed using:  *   Most-frequent-value imputation      *   One-Hot Encoding       OneHotEncoder(handle_unknown="ignore") was used to safely handle categorical inputs.  Machine Learning Model ----------------------  The project uses **Logistic Regression** for binary classification.  Logistic Regression was selected because it is:  *   Suitable for binary classification      *   Simple and interpretable      *   Computationally efficient      *   Appropriate for a small structured dataset      *   Easy to integrate into a prediction application       The final model was implemented as a complete Scikit-learn Pipeline containing:  *   Data preprocessing      *   Missing-value handling      *   Feature scaling      *   One-hot encoding      *   Logistic Regression classifier       Train-Test Split ----------------  The dataset was divided into:  *   **80% Training Data**      *   **20% Testing Data**       A fixed random state of 42 was used to make the experiment reproducible.  The split was stratified according to the target variable.  Model Performance -----------------  The model was evaluated on the held-out test dataset containing **61 samples**.  ### Results  *   **Accuracy:** 88.52%      *   **Precision:** 83.87%      *   **Recall:** 92.86%      *   **F1-Score:** 88.14%       ### Classification Report  No Heart Disease:  *   Precision: 93%      *   Recall: 85%      *   F1-Score: 89%       Heart Disease:  *   Precision: 84%      *   Recall: 93%      *   F1-Score: 88%       The model achieved a relatively high recall for the heart disease class, meaning that it correctly identified most of the heart disease cases in the held-out test set.  Confusion Matrix ----------------  The confusion matrix obtained from the test dataset was:  *   True Negative (TN): 28      *   False Positive (FP): 5      *   False Negative (FN): 2      *   True Positive (TP): 26       Matrix:  No Disease predicted as No Disease: **28**  No Disease predicted as Disease: **5**  Disease predicted as No Disease: **2**  Disease predicted as Disease: **26**  The relatively low number of false negatives is important from a healthcare-risk screening perspective. However, the model is not clinically validated and should not be interpreted as a diagnostic system.  Model Saving ------------  After training and evaluation, the complete Machine Learning pipeline was saved using Joblib.  Saved model:  model/heart_disease_model.pkl  The saved pipeline contains the preprocessing steps and Logistic Regression model, allowing the same transformations to be applied when making predictions through the Streamlit application.  Streamlit Application ---------------------  A Streamlit-based web application was developed to provide an interactive interface for the trained model.  The application allows users to enter patient information such as:  *   Age      *   Sex      *   Chest Pain Type      *   Resting Blood Pressure      *   Cholesterol      *   Fasting Blood Sugar      *   Resting ECG      *   Maximum Heart Rate      *   Exercise-Induced Angina      *   Oldpeak      *   Slope      *   Number of Major Vessels      *   Thalassemia       After entering the information, the application generates:  *   Predicted risk category      *   Estimated model probability       The application displays either:  **Higher Risk of Heart Disease**  or  **Lower Risk of Heart Disease**  along with the estimated probability.  Application Validation ----------------------  The Streamlit application was tested using multiple manually selected patient profiles.  One of the final validation tests used the following patient profile:  *   Age: 65      *   Sex: Male      *   Chest Pain Type: Asymptomatic      *   Resting Blood Pressure: 150      *   Cholesterol: 280      *   Fasting Blood Sugar: No      *   Resting ECG: Normal      *   Maximum Heart Rate: 110      *   Exercise-Induced Angina: Yes      *   Oldpeak: 2.5      *   Slope: Flat      *   Major Vessels: 2      *   Thalassemia: Reversible Defect       Final validation result:  **Prediction:** Higher Risk of Heart Disease  **Estimated Model Probability:** 99.53%  The same patient data was tested directly using the saved model in the Jupyter Notebook and through the Streamlit application.  Both produced:  **Prediction: 1**  **Probability: 99.53%**  This confirmed that the saved model and Streamlit application were processing the inputs consistently.
